# **Fichiers Super Saver**

Scripts to backup files (Windows compatibility only for now).
This collection contains four main parts :
- FSS Legacy, Discord bot
- Windows Personal Files Saver
- Directory Sanitizer
- Directories Merger

# Getting started

## Installation
Make sure to install latest version of Python and run the configure.bat file.

# Features
- backup messages and attachements from a Discord server (where the Fichiers Super Saver bot is)
    - not working with the latest version of Python
- backup from the common directories of Windows PC
    - not working with Steam files yet
    - wip : options to specify which file to backup
- backup a specified directory and clean the directory
    - wip : sanitize the directory
- wip : merge directories
